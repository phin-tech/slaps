## A new Settings window

Settings is a sidebar of sections now, with a search box over them: General, Alerts, Video, Battery, Calendars,
Filters, Tabs, Shortcuts, Other Apps, Command Line and Updates. Type "youtube", "beta" or "sharing" and it goes to the
section that has it. Each section says what it's for at the top.

## The command line, from the app

Settings › Command Line puts `slaps` in `~/.local/bin` with one click, and shows how it's used, typed out in a little
terminal you can replay or copy the commands from.

## A new welcome window

The first-launch window goes a step at a time: calendars, when alerts go up (with a test alert), reminders, a video,
the keys worth knowing, the command line, and opening at login. ← and → go between steps; finished ones are ticked.
Settings › General shows it again.

## Undo

Dismiss a tab, or all of them, from the menu bar and an Undo shows for a few seconds to put them back.
